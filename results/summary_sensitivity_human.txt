# Sensitivity analysis: human baseline sample size

Data directory: alienbench/data.bak.1778065662
Human sample: human/prolific-baseline, prompt variant 'baseline'.

## Realized design
  Human responses          N = 100
  Generations per model    n = 30
  Model comparisons            10
  Human Ward mean (0-10)       1.93 (SD 1.89)
  95% CI half-width            0.375 Ward points

## Minimum detectable effect, Ward total score (80% power, two-sided)
  alpha = 0.05            d = 0.588 (1.09 Ward points)
  alpha' = 0.0050        d = 0.771 (1.42 Ward points)
  Mann-Whitney, alpha = 0.05   rank-biserial r = 0.334
  Mann-Whitney, alpha' = 0.0050  rank-biserial r = 0.430

## Minimum detectable effect by comparison design (N human held at 100)
  Comparison                                                n       d     pts   d(Bonf)  pts(Bonf)
  ----------------------------------------------------------------------------------------------
  Single model, baseline prompt                            30   0.588    1.09     0.771       1.42
  Balanced reference                                      100   0.398    0.74     0.521       0.96
  Single model, pooled over conditions                    180   0.351    0.65     0.458       0.85
  Full model panel, baseline prompt                       300   0.324    0.60     0.423       0.78
  Human sample as the only constraint                     inf   0.280    0.52     0.365       0.67

## Where the constraint sits
  Detectable gap at N = 100, n = 30:        1.42 Ward points
  Detectable gap as N -> infinity, n = 30:  0.94 Ward points
  Reduction available from more humans:   0.48 Ward points (34%)
  Anchor precision at N = 100:  +/- 0.375 Ward points
  Anchor precision at N = 200:  +/- 0.263 Ward points (gain 0.111)

## Observed gaps against the detectable threshold
  Resolved (|d| >= MDE):   7/10 models
  Unresolved:              3/10 models [google/gemini-3.1-pro-preview, mistralai/mistral-large-2411, openai/gpt-5.4]
  Smallest resolved gap:   meta-llama/llama-4-maverick +1.47 Ward points (d = +0.80), 1.04x the MDE
